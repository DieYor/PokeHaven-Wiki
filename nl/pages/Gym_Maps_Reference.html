Gym-map referentie

Alle gym- en league-maps op PokeHaven EU: special items, structure-IDs, regio-tafels, hoe LumyMon maps bouwt, en staff-grants.

Inhoud

    Wat een gym-map is

    Een afgewerkte gym-map is een filled map met LumyMon-componenten die naar een CobbleVerse-structure wijzen (gym / league). Het is geen vaste X/Z uit de pack — de cartography-tafel zoekt een structure in jouw wereld en schrijft marker + coördinaten op de map.

    1. Craft het special item van de leader (REI). Dat item draagt lumymon:structure_name (en meestal dimensie / map-decoratie).
    2. Doe een verse Empty Map + dat item in de juiste regio-cartography-tafel.
    3. LumyMon lokaliseert de structure en geeft een afgewerkte map (hover = coördinaten).
    Belangrijk

    Open een Empty Map nooit eerst in de wereld. Dan is hij onbruikbaar voor gym-crafts. Spelersgids: Gym-maps.

    Hoe maps “gemaakt” worden (technisch)

    LaagRol
    CobbleVerse worldgenStructures zoals cobbleverse:misty / cobbleverse:valerio (Johto+ via regio-DP).
    LumyMon-receptenSpecial items met components: item → structure-ID.
    Regio-cartography-tafelBlock entity: Empty Map + key → exploration map.
    Map Guide-villagerTrades afgewerkte maps als de matching tafel naast een unemployed villager staat.
    PokeHaven CoreGymMapCatalog + GymMapGrant (zelfde LumyMon-finalize als de tafel). Admin UI → Maps.

    Staff-grant keys = korte id (misty, valerio, blaine) → cobbleverse:<key>. Blaine zoekt in de Nether.

    Regio-unlock vs wild spawns

    Wilde Pokémon uit latere regio’s kunnen eerder al spawnen. Gym-structures + regio-cartography unlocken pas met champion + datapack:

    Eerste championDatapackDaarna
    BlueCOBBLEVERSE-Johto-DP.zip1× server restart
    LanceCOBBLEVERSE-Hoenn-DP.zip1× server restart
    RoccoCOBBLEVERSE-Sinnoh-DP.zip1× server restart

    Zips staan onder Apex datapacks/extra/ tot enable. Oude Kanto-gyms blijven bestaan.

    Spelersmethodes (kort)

    1. Craft: special item + Empty Map op de regio-tafel.
    2. Map Guide: regio-tafel naast unemployed villager → traden.
    3. Starter: Brock-kit = tafel + Brock-key + Empty Map.

    Staff-notities (PokeHaven)

    • Admin-panel → Maps: map geven aan jezelf / speler / online (GymMapGrant).
    • Grant faalt met “structure not found”? Structure zit nog niet in geladen chunks, of regio-DP is niet geladen (restart na champion-unlock).
    • Map Guide-trades: refresh via /pha na datapack-wijzigingen aan trade-pools.
    • PokeHaven blokkeert het openen van Empty Maps die alleen ogen als gym-map (GymMapUseGuard).
