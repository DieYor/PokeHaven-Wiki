Gym map reference

Every gym and league map on PokeHaven EU: special items, structure IDs, region tables, how LumyMon builds maps, and staff grant notes.

Contents

    What a gym map is

    A finished gym map is a vanilla-style filled map with LumyMon components that point at a CobbleVerse structure (gym / league building). It is not a fixed X/Z bookmark baked into the pack — the cartography table finds a structure instance in your world, then writes marker + coordinates onto the map.

    1. Craft the leader’s special item (REI). That item carries lumymon:structure_name (and usually lumymon:dimension_id / map decoration).
    2. Put a fresh Empty Map + that item into the matching region cartography table.
    3. LumyMon localizes the structure and outputs a finished map you can hover for coordinates.
    Important

    Never open an Empty Map in the world first. That converts it into a useless filled map for gym crafting. Always use a fresh Empty Map in the table. Player walkthrough: Gym maps.

    How maps are “made” (tech)

    LayerWhat it does
    CobbleVerse worldgenDefines structures like cobbleverse:misty / cobbleverse:valerio (region DPs gate Johto+).
    LumyMon recipesSpecial items with NBT/components binding item → structure ID.
    Region cartography tableBlock entity that consumes Empty Map + key item and writes the exploration map.
    Map Guide villagerTrades finished maps for that region when the matching table is placed next to an unemployed villager.
    PokeHaven CoreGymMapCatalog lists leaders for staff grants; GymMapGrant calls LumyMon’s finalize logic (same as the table). Admin UI → Maps tab.

    Staff grant keys match the catalog short id (e.g. misty, valerio, blaine) → structure cobbleverse:<key>. Blaine maps search the Nether.

    Region unlock vs wild spawns

    Wild Pokémon from Johto/Hoenn/Sinnoh can appear earlier from the main pack. Gym structures and region cartography content unlock with champion + datapack:

    First championDatapackThen
    BlueCOBBLEVERSE-Johto-DP.zip1× server restart
    LanceCOBBLEVERSE-Hoenn-DP.zip1× server restart
    RoccoCOBBLEVERSE-Sinnoh-DP.zip1× server restart

    Zips live under Apex datapacks/extra/ until enabled. Old Kanto gyms stay after later unlocks.

    Player methods (summary)

    1. Craft: special item + Empty Map on the region table.
    2. Map Guide: place that region’s cartography table next to an unemployed villager → trade maps.
    3. Starter: Brock kit already includes table + Brock key + Empty Map.

    Staff notes (PokeHaven)

    • Admin panel → Maps: grant a leader map to self / player / online (uses GymMapGrant).
    • If grant fails with “structure not found”, the structure may not exist in loaded chunks yet — explore / generate more of that dimension, or the region DP is not loaded (restart after champion unlock).
    • Map Guide trades: /pha map-guide refresh exists for trade-pool revisions after datapack edits.
    • PokeHaven blocks opening Empty Maps that are only named like gym maps but still empty (GymMapUseGuard).
