Koga (Johto)

Koga (Johto) — Poison specialist on PokeHaven EU.

Contents

    Walkthrough — Pino to Johto Koga

    Prepare

    Psychic and Ground help into Poison. Not the same fight as Kanto Koga — check this page’s team.

    • Coverage: Psychic and Ground help into Poison. Fast removers beat stall.
    • Leader party levels: about 80–80
    • Approx cap while this fight is next: ~85 — Level cap
    • Heals, status cures, spare balls, claimed base / waystone to retreat to
    • Same End tower — restock after Pino.

    Craft the map

    1. Search Koga in REI and craft Loaded Dice.
    2. Craft a fresh Empty Map.
    3. Combine Empty Map + Loaded Dice in the Johto Cartography Table (or trade a Map Guide villager).
    4. Hover the finished map for coordinates. Details: Gym maps.
    Important

    Do not open the Empty Map in the world first — that ruins it for gym crafting. Use the correct region cartography table.

    Fight tips

    Different team than Kanto Koga (Naganadel line, etc.). Check the team table below.

    1. Travel with heals; activate waystones on the route.
    2. Elite Four / Champion: full heal between rooms.
    3. Heal, then challenge Koga.
    4. Win → level cap rises → next: Bruno.
