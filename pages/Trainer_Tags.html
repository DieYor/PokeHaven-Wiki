Trainer tags

Pick a cosmetic chat tag on PokeHaven EU with /prefix. Looks only — no gameplay advantages.

Contents

    Cosmetic only
    Trainer tags change how your name looks in chat. They do not affect shiny odds, catch rates, XP, claims, or gym progression.

    How to use

    1. Join with the PokeHaven EU Client (the Prefix mod is already in the zip).
    2. Type /prefix in chat.
    3. A Pokédex-style menu opens with the tags you own.
    4. Click a tag to equip it — or choose No Tag to hide every trainer tag.
    Empty menu?
    If you only see No Tag, you have not unlocked a donor tag yet. Donate via Discord (staff logs lifetime totals) — then rejoin or ask staff if the group did not sync.

    Donor tags

    Lifetime donation totals unlock Discord roles and matching in-game tags. Thresholds:

    LifetimeTagLooks like
    €10+Supporteraqua [Supporter]
    €50+Patrongold [Patron]
    €100+Benefactorlight purple [Benefactor]
    —No TagHides all trainer tags

    Higher tiers keep access to lower tags — pick whichever you want in /prefix.

    Donation links and instructions live in Discord. Optional support only; the server stays free to play.

    Requirements

    • Server: LuckPerms + PokeHaven Prefix mod
    • Client: same Prefix mod (bundled in the PokeHaven EU Client zip)
    • Staff tags (Admin / Mod) only appear if you have those groups — most players never see them

    Quick FAQ

    QuestionAnswer
    Does a tag help in battles?No — cosmetic only.
    Can I hide my tag?Yes — open /prefix → No Tag.
    I donated but see no tagAsk staff in a Discord ticket (include Discord name + in-game name). Then use /prefix.
