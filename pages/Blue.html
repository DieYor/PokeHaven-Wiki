Blue

Blue — Mixed specialist. Team data from the CobbleVerse RCT datapack used on PokeHaven EU.

Contents

    Prepare

    Cover many types. Unique drop notes mention Ancient Origin Ball on some packs.

    • Team levels: about 100–100 (leader party from pack data)
    • Bring heals, status cures if needed, and spare Poké Balls
    • Approx cap while this fight is next: ~105 — Level cap

    Get the map

    1. Craft / trade Rival Sling (search the leader’s name in REI).
    2. Craft a fresh Empty Map.
    3. Combine Empty Map + Rival Sling in the Kanto Cartography Table (or trade a Map Guide villager).
    4. Hover the finished map for coordinates. Details: Gym maps.
    Important

    Do not open the Empty Map in the world first — that ruins it for gym crafting.

    Fight

    1. Travel with heals and a covered team.
    2. Clear gym trainers if you need XP or money.
    3. Heal, then challenge the leader.
    4. Win → level cap rises → next: the next region.
